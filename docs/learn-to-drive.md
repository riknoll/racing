# Learn to drive

Start the **How to Drive** lesson directly, without opening the racing menu.
The lesson teaches acceleration, reversing, steering, driving over grass, and
slowing down for tight corners using the normal racing controls.

```sig
racing.learnToDrive()
```

## Example

```blocks
racing.learnToDrive()
```

The lesson runs in its own scene. When it finishes, the previous scene is restored
and the program continues with the next block.

Use [start racing game](start-game.md) instead to open the full menu, or
[race on a track](race-on-track.md) to start a race directly.

```package
racing=github:riknoll/racing
```
